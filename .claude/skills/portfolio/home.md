# Главная

Раздел харнеса портфолио. Главная — одна длинная страница из слайдов на общем фоне hero: **Hero → плитки кейсов → «Обо мне» → «Отраслевая прожарка»** (`src/components/HomeContent.astro`, всё внутри `<Hero>`). Общие правила (типографика, числа, тексты, картинки, проверки, деплой) — в `SKILL.md`, здесь только своё для главной. Подробная история решений по каждому блоку — `log.md`.

## 1. Сетка и шапка

- Поля `--gutter`: **160 / 100 / 20px** (от 1280 / 768–1279 / мобила). Контент за поля не заходит; фоны в край — с `data-bleed`, их содержимое держит поля само.
- Шапка `--header-h` 64px, фиксированная и прозрачная: слева логотип, справа — «CV», «Контакты ▾», планета (язык). Элементы по центру 64px по вертикали, не за полями. Тень у логотипа и планеты — `--header-shadow`.
- Значения — только токены `src/styles/tokens.css`. Временная сетка — `DEV_GRID` (CLAUDE.md).

## 2. Слайды и прокрутка

- Фон hero (WebGL-градиент) липкий на всю страницу; монохром фона — функция от прокрутки (`grayAt` в `Hero.astro`): к плиткам — серый, на «Обо мне» — снова цветной.
- Каждый новый раздел главной — **слайд**: `data-snap` на корне, верх встаёт на `--tiles-final-top` (100px от верха экрана). Доводка после остановки прокрутки — свой snap в `Hero.astro` (в пределах половины экрана), на сенсорных экранах выключена.
- Анимации — GSAP/ScrollTrigger через `onPage()` (`motion.ts`), с учётом `reducedMotion` (при reduced motion — всё сразу на месте, бесконечные движения стоят).
- Высоты экрана — `svh`/`lvh`, не `dvh` (в iOS Safari `dvh` меняется при прокрутке).
- Перезагрузка всегда открывает первый слайд; смена языка меняет только текст и сохраняет место.

## 3. Заголовки и текст разделов

| Элемент | Токены |
|---|---|
| Заголовок раздела («Обо мне», «Отраслевая прожарка») | `--text-display`, 800, `--leading-display`, `--tracking-display`, белый |
| Заголовок hero | `--text-display`, 800, тень `--hero-text-shadow`, первое слово перекидное |
| Подпись hero | `--text-lead`, тень `--hero-lead-shadow` |
| Текст «Обо мне» | `--text-about`, белый, ключевые фразы — жёлтым маркером `<mark>` (`--case-accent`, чёрный текст) |
| Чипсы hero | `--text-chip`, белые таблетки 88%, тёмный текст, без тени |
| Заголовок / подпись / год плитки | `--text-tile-title` 800 / `--text-tile-lead` / `--text-tile-lead` |

Тексты — только `ui.ts` + `t()` (RU и EN сразу).

## 4. Плитки кейсов

- Основные плитки — 2 × 2 (на мобиле в колонку), пропорция `--tile-ratio` (4:4.5, мобила 3:4.5), зазор `--tile-gap` 100 / 72 / 52px, скругление `--tile-radius`, поля `--tile-padding`.
- Внутри: год → название → подпись (3 строки на 1728) → картинка до нижнего края (`object-fit: cover`, сверху по центру).
- Плашка — пастельный цвет плитки `--tile-color-1…4` с прозрачностью `--tile-bg-opacity` + крупный принт «листья» (`PRINTS`); мелких повторяющихся узоров нет.
- Картинка плитки — холст 1200 × 1632, прозрачный фон, композиция из экранов обложки (центр 560px в x 320, y 0; боковые 82% в x 90 и 651, y 120), верх композиции у всех плиток — y 0 (правило в `product.md` → «Тексты и цифры»).
- Готовый кейс: ссылка в названии растянута на плитку, `data-case-link` (открывается в модалке); данные — `TILE_CASES`, `TILE_IMAGES`, `TILE_LEADS` в `Tiles.astro`. Нет картинки — заглушка «Кейс в разработке» (три экрана-заготовки), дописывается — метка поверх картинки (`TILE_IN_PROGRESS`).
- Порядок — по убыванию дат. Под основными — карточки без картинки, 3 / 2 / 1 в ряд, высота не меньше ширины × `--tile-small-ratio`, ряды одной высоты.
- Наведение (только мышь, `hover: hover`): приподнимается на 10px (через `top`, transform занят GSAP), тень, плашка плотнее, принт разворачивается.
- Бегущая строка логотипов — между рядами, в край экрана, фирменные цвета, ссылки на сайты, пауза только под курсором и при фокусе с клавиатуры.

## 5. «Обо мне» и контакты

- Заголовок раздела + абзацы (до 52rem) слева, тёмная карточка контактов справа от 1024px (на узких — под текстом): чёрный 92%, скругление 24px, мягкая тень.
- Ссылки — со стрелкой ↗, на наведении сдвигается стрелка; телефон на наведении — жёлтый. QR — на белой подложке (без неё MAX не считывается).

## 6. «Отраслевая прожарка»

- Заголовок как у «Обо мне», 4 плитки 3:4 в один ряд от 768px (на телефоне 2 × 2), скругление 24px.
- Плитка кейса — «плоский постер» (`roast.md` → «Плитка на главной»); без кейса — тёмная заготовка с номером и пульсирующей меткой «Кейс в разработке».
- Те же плитки — блок «Другие кейсы» внизу кейса прожарки (`<Roast compact current>`).
