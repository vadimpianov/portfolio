## Глобальное правило №1 — Portfolio ≠ Arno

**Portfolio и Arno — два разных, никак не связанных проекта.**

- Не используем из Arno ничего: код, пакеты, конфиги, дизайн-токены, инфраструктуру, CI, хуки, агентов, `/build`-воркфлоу, `CLAUDE.md`, `Rules.md`.
- Не читаем и не пишем в репозиторий `arnomake/arno` в рамках этого проекта.
- Правило из Arno можно перенести, только если отдельно спросить пользователя про **конкретное** правило и получить явное «да». Молча ничего не переносим.

## Общение и язык

- Общение с пользователем — **на русском**.

## Сетка (обязательно для всех страниц и компонентов)

- **Поля контента** — `--gutter`: **100px** слева и справа (от 768px), **20px** на мобильных. Контент за поля не заходит. Фоны (например, градиент hero) могут идти в край — такие блоки помечаются `data-bleed`, а их собственный контент держит поля сам.
- **Шапка** — полоса `--header-h` = **52px** сверху, зафиксирована (при скролле на месте). Элементы шапки центрируются по вертикали в этих 52px и по горизонтали не выходят за `--gutter`.
- Значения — только токены из `src/styles/tokens.css`, не хардкодим.

### Временная сетка (dev-оверлей)

Модуль `src/components/DevGrid.astro`: вертикальные линии по полям на всю высоту + горизонтальная линия на 52px от края до края, контрастные к фону (`mix-blend-mode: difference`). Флаг — `DEV_GRID` в `src/config/dev.ts`.

- «**Включи сетку**» → `DEV_GRID = true`; «**Выключи сетку**» → `DEV_GRID = false`. Затем коммит → пуш → деплой, как после любого шага.

## Выбор языка (i18n)

- Маршруты: `/ru/…` и `/en/…`.
- При заходе на `/` edge-функция (Cloudflare Pages Functions / middleware) смотрит страну посетителя (`request.cf.country`):
  - `RU` → редирект на `/ru/`
  - любая другая страна → редирект на `/en/`
- Есть переключатель языка. Ручной выбор запоминается (cookie) и **имеет приоритет над геолокацией**.
- Каждая страница и каждый MDX-кейс существует в обеих локалях.

## Деплой (Cloudflare Pages)

Когда пользователь говорит «задеплой», делаем всё по этой инструкции **без переспрашивания**. Пользователь не должен повторять её заново.

**Деплоим сразу после каждого завершённого шага** (не дожидаясь «задеплой»): коммит → пуш → деплой → проверка → ссылка пользователю.

- Проект Cloudflare Pages: **`vadimpianov`**, production-ветка **`main`**, адрес **https://vadimpianov.pages.dev**
- Ключи — в переменных окружения облачного окружения: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`

### Шаги

1. **Подготовить ключи.** Значения могли быть сохранены в угловых скобках (`<…>`). Wrangler такие отвергает, поэтому перед командами снимаем скобки и пробелы:
   ```sh
   export CLOUDFLARE_ACCOUNT_ID="$(printf %s "$CLOUDFLARE_ACCOUNT_ID" | tr -d '<> ')"
   export CLOUDFLARE_API_TOKEN="$(printf %s "$CLOUDFLARE_API_TOKEN" | tr -d '<> ')"
   ```
   (Правильнее исправить сами значения в настройках окружения — сказать об этом пользователю, если скобки есть.)
2. **Собрать** (из корня репозитория):
   ```sh
   pnpm install --frozen-lockfile && pnpm build
   ```
3. **Проверить, что проект существует; если нет — создать:**
   ```sh
   npx wrangler pages project list
   npx wrangler pages project create vadimpianov --production-branch main   # только если его нет
   ```
4. **Выложить в production** — строго из корня репозитория, чтобы вместе с `dist/` задеплоилась папка `functions/` (редирект по языку):
   ```sh
   npx wrangler pages deploy dist --project-name vadimpianov --branch main
   ```
5. **Проверить:**
   ```sh
   curl -sSI https://vadimpianov.pages.dev/ru/   # 200
   curl -sSI https://vadimpianov.pages.dev/en/   # 200
   curl -sS -o /dev/null -D - https://vadimpianov.pages.dev/   # 302, Location: /en/ (или /ru/ из РФ)
   ```
   Для `/` — именно GET, не `curl -I`: функция обрабатывает только GET, на HEAD отдаётся статический `index.html` (200).
6. **Обновить «Состояние проекта»** ниже: дата деплоя, адрес. Закоммитить и запушить.

### Если не выходит

- **`fetch failed` / 403 от прокси на `api.cloudflare.com`**: это сетевая политика облачного окружения. Сказать пользователю: меню окружения в заголовке сессии → Edit → Network access → добавить в разрешённые домены `api.cloudflare.com` и `vadimpianov.pages.dev` (или выбрать уровень доступа шире). Не обходить.
- **`Invalid account ID "<…>"`**: см. шаг 1.
- **`Invalid format for Authorization header` [6111]**: в `CLOUDFLARE_API_TOKEN` лежит не API-токен (например, значение с `|` или Global API Key). Нужен API Token: dash.cloudflare.com → My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers» (или Custom: Account → Cloudflare Pages → Edit). Попросить пользователя заменить значение в настройках окружения.
- В CLAUDE.md не писать «задеплоено», пока шаг 5 не прошёл.

## Состояние проекта

Скаффолд готов (2026-09-25): Astro 7 + TS (strict) + MDX + i18n `/ru/`, `/en/` + GSAP/ScrollTrigger + Lenis + View Transitions.

- `pnpm dev` / `pnpm build` (включает `astro check` и проверку типов `functions/`) / `pnpm format`
- `functions/index.ts` — редирект с `/`: cookie `lang` → страна (`RU` → `/ru/`) → `/en/`
- `src/i18n/` — строки интерфейса (`ui.ts`), хелперы ссылок, выборка кейсов по локали
- `src/content/{ru,en}/cases/*.mdx` — кейсы; `hello-world.mdx` тестовый, удалить при появлении настоящих
- `src/scripts/motion.ts` — Lenis + GSAP; анимации страницы регистрируются через `onPage()`, чистятся сами при переходах
- `src/components/Hero.astro` + `src/scripts/hero-gradient.ts` — hero на весь экран с WebGL-градиентом, на курсор **не** реагирует. Палитра — `--hero-colors` в `Hero.astro`: кольцо со стопами «#hex N%» (последний цвет = первому). **Жёлтый всегда посередине экрана**: палитра не прокручивается, центр экрана привязан к `--hero-anchor` (центр жёлтой зоны), изгибы в центре вычитаются. **Пять цветов** (после «Янтаря» убрана половина: персик, фуксия, орхидея, тени): жёлтый (печёный `#e0a33a` + медовый `#f0bd4f`, ~30% кольца → **на экране 45–60%**; `--hero-anchor-area: 30% 52%` — плотность лент подстраивается под наклон, чтобы площадь жёлтого не зависела от него; окно палитры 0.7…0.92 круга; замер: среднее 55%, ~75% кадров в 45–60%, выбросы 38–74% в сильные изгибы) → розовый `#ff6fae` → сиреневый `#b58cff` → голубой `#7ccfff` → крем `#f6e7c1` → жёлтый. **Крем — растушёванный светлый градиент с обеих сторон жёлтого** (точки `--hero-soft`: вокруг них шейдер усредняет палитру в широком окне → мягкое свечение, а не полоска; остальные границы не размываются): голубой → крем → жёлтый → крем → розовый (единственное исключение из правила «один цвет — один кусок», по просьбе пользователя). Цвета смешиваются в **OKLab** (не в RGB — там середины переходов выцветали в «пыльные»). Соседи подобраны под чистые стыки (жёлтый→розовый = лососевый, розовый→сиреневый = орхидея, сиреневый→голубой = барвинок; голубой→жёлтый только через крем, иначе грязно-зелёный) — при добавлении цветов проверять середину стыка. **Каждый цвет — один сплошной участок кольца, не дробим на части**; на экране ~0.92 круга (строго меньше одного), чтобы цвет не повторялся; между голубым и жёлтым — широкий кремовый мостик `#f6e7c1` (~13% кольца), растянутый длинными переходами. Поверх градиента — чёрный слой `.hero__shade` — сейчас 0% (выключен). Поверх градиента, но под текстом — наклонная сетка `.hero__stripes` (**сейчас скрыта**, `display: none`): линии 2px под 45° сверху-слева вниз-направо, промежуток 8px (шаг 10px), цвет `#141414`, прозрачность слоя 2.5%, без заливки. **Анимация всегда стартует с одного и того же кадра** — `startTime: 102` в пресете `soft`, кадр по скриншоту пользователя (розовый сверху, персик, жёлтый в центре, кремовая полоса, голубой внизу); при изменении формулы потока или палитры стартовый кадр надо подобрать заново. Форма — «гнущийся лист»: ленты близки к горизонтали (~20°), направление покачивается ±30°. **Принцип: выступ на одном краю ленты = вмятина напротив, на другом краю** — ленты гнутся вместе, толщина сохраняется (±15%), цвета не раздуваются и не расталкивают соседей; палитра не прокручивается (прокрутка выглядела как «выталкивание» одного цвета другим и уводила жёлтый с экрана). Изгибы — сдвиг поперёк лент, зависящий в основном от координаты вдоль лент (**только крупные размашистые изгибы** — два крупных слоя шума + одна длинная пологая волна; мелкие изгибы запрещены); хаос — «порывы» силы изгибов (0.2…1.4), непостоянная, но **всегда положительная** скорость дрейфа изгибов вдоль лент (оба слоя в одну сторону — **движение обратно запрещено**); «вдохи» — жёлтая лента время от времени растягивается по высоте до ×1.5; **завихрения** — два плавающих центра (плывут в одну сторону) подкручивают ленты до ±90° по/против часовой: лента может заворачиваться крюком/S-петлёй (поворот по радиусу — обратимый, без дырок и пиков), быстрая эволюция; производная поперёк < 1, поэтому нет замкнутых форм («дырки», мишени) и острых пиков. Отвергнуто: шум-пятна, разнонаправленный дрейф слоёв, течение вдоль лент со скольжением слоёв, цепочка общих деформаций (раздувала одни цвета и сжимала другие). Пресеты `HERO_PRESETS`: `soft` (текущий: медленная смена оттенков, `edge: 0.8` — все переходы на 20% уже исходных, `timeScale: 0.53` — скорость движения) и `vivid` (быстрее, границы резче). Пресет по умолчанию — в `Hero.astro`. Палитра общая для обоих пресетов
- `src/styles/tokens.css` — сетка, шрифт, цвета, шкала текста. Шрифт — **Onest Variable** (`@fontsource-variable/onest`, self-hosted): заголовки 800, текст 400
- `src/components/Logo.astro` — логотип PIANOV векторным SVG (монолиния, круглые концы, `currentColor`), в шапке слева, ведёт на главную локали. Высота — токен `--logo-h`
- `src/components/LanguageSwitcher.astro` — переключатель языка в шапке справа: иконка планеты 24×24px (линия 1.7px), по нажатию сразу переключает на другой язык (RU ↔ EN) и пишет cookie `lang`
- Hero: заголовок «Архитектура, дизайн, процессы, ИИ» + подпись (`home.intro.*` в `ui.ts`), прижат к левой линии `--gutter`, по центру экрана по вертикали
- Второй слайд: фон hero липкий (`.hero__bg`, sticky) на оба слайда. Сцена скролла — в `Hero.astro` (ScrollTrigger, scrub). Длина сцены = путь плиток от старта (`--tiles-start` 100dvh, низ экрана) до места под шапкой с зазором `--tiles-top-gap` 40px. Плитки (`src/components/Tiles.astro`, 2 × 2, на мобиле в колонку, пропорция `--tile-ratio` 4:4.5 (на мобиле 3:4.5), зазор `--tile-gap` 100px (на мобиле 40px), от линии до линии сетки; внутри — заголовок, подпись и условная картинка до нижнего края, тексты-заглушки `tiles.placeholder.*` в `ui.ts`) подтягиваются по очереди слева направо (`STAGGER` 0.15 сцены между колонками; каждая следующая колонка стартует ниже на `COL_DROP` 240px; ждущая колонка держится на месте экрана) и проявляются: плашка (`.tiles__plate`) opacity 0.1 → 1, заливка `--tile-bg` белый 50% прозрачности, у каждой плашки свой фоновый принт (`data-print`: dots / stripes / grid / rings, цвет `--tile-print`); содержимое (`.tiles__body`: заголовок, подпись, картинка) — с запаздыванием `BODY_LAG` и своим параллаксом `BODY_SHIFT`, opacity 0 → 1, в финале без прозрачности. Подтягивание, параллакс и проявление идут до самого финала сцены (`ALIGN` = 1): в финале плитки выровнены по верху под шапкой, градиент полностью монохромный (`grayscale`). Текст hero растворяется (1 → 0) и исчезает, когда целиком уходит под шапку
- `site` в `astro.config.mjs` — заглушка, заменить на реальный домен
