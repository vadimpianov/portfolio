## Глобальное правило №1 — Portfolio ≠ Arno

**Portfolio и Arno — два разных, никак не связанных проекта.**

- Не используем из Arno ничего: код, пакеты, конфиги, дизайн-токены, инфраструктуру, CI, хуки, агентов, `/build`-воркфлоу, `CLAUDE.md`, `Rules.md`.
- Не читаем и не пишем в репозиторий `arnomake/arno` в рамках этого проекта.
- Правило из Arno можно перенести, только если отдельно спросить пользователя про **конкретное** правило и получить явное «да». Молча ничего не переносим.

## Общение и язык

- Общение с пользователем — **на русском**.
- Сайт двуязычный: RU + EN. Работаем с текстами на русском, английскую версию Claude делает **сразу и параллельно** (без отдельной просьбы).

## Сетка (обязательно для всех страниц и компонентов)

- **Поля контента** — `--gutter`: **100px** слева и справа (от 768px), **20px** на мобильных. Контент за поля не заходит. Фоны (например, градиент hero) могут идти в край — такие блоки помечаются `data-bleed`, а их собственный контент держит поля сам.
- **Шапка** — полоса `--header-h` = **52px** сверху, зафиксирована (при скролле на месте). Элементы шапки центрируются по вертикали в этих 52px и по горизонтали не выходят за `--gutter`.
- Значения — только токены из `src/styles/tokens.css`, не хардкодим.

### Временная сетка (dev-оверлей)

Модуль `src/components/DevGrid.astro`: вертикальные линии по полям на всю высоту + горизонтальная линия на 52px от края до края, контрастные к фону (`mix-blend-mode: difference`). Флаг — `DEV_GRID` в `src/config/dev.ts`.

- «**Включи сетку**» → `DEV_GRID = true`; «**Выключи сетку**» → `DEV_GRID = false`. Затем коммит → пуш → деплой, как после любого шага.

## Выбор языка (i18n)

- Маршруты: `/ru/…` и `/en/…`.
- При заходе на `/` edge-функция (Cloudflare Pages Functions / middleware) смотрит страну посетителя (`request.cf.country`):
  - `RU` → редирект на `/ru/`
  - любая другая страна → редирект на `/en/`
- Есть переключатель языка. Ручной выбор запоминается (cookie) и **имеет приоритет над геолокацией**.
- Каждая страница и каждый MDX-кейс существует в обеих локалях.

## Деплой (Cloudflare Pages)

Когда пользователь говорит «задеплой», делаем всё по этой инструкции **без переспрашивания**. Пользователь не должен повторять её заново.

**Деплоим сразу после каждого завершённого шага** (не дожидаясь «задеплой»): коммит → пуш → деплой → проверка → ссылка пользователю.

- Проект Cloudflare Pages: **`vadimpianov`**, production-ветка **`main`**, адрес **https://vadimpianov.pages.dev**
- Ключи — в переменных окружения облачного окружения: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`

### Шаги

1. **Подготовить ключи.** Значения могли быть сохранены в угловых скобках (`<…>`). Wrangler такие отвергает, поэтому перед командами снимаем скобки и пробелы:
   ```sh
   export CLOUDFLARE_ACCOUNT_ID="$(printf %s "$CLOUDFLARE_ACCOUNT_ID" | tr -d '<> ')"
   export CLOUDFLARE_API_TOKEN="$(printf %s "$CLOUDFLARE_API_TOKEN" | tr -d '<> ')"
   ```
   (Правильнее исправить сами значения в настройках окружения — сказать об этом пользователю, если скобки есть.)
2. **Собрать** (из корня репозитория):
   ```sh
   pnpm install --frozen-lockfile && pnpm build
   ```
3. **Проверить, что проект существует; если нет — создать:**
   ```sh
   npx wrangler pages project list
   npx wrangler pages project create vadimpianov --production-branch main   # только если его нет
   ```
4. **Выложить в production** — строго из корня репозитория, чтобы вместе с `dist/` задеплоилась папка `functions/` (редирект по языку):
   ```sh
   npx wrangler pages deploy dist --project-name vadimpianov --branch main
   ```
5. **Проверить:**
   ```sh
   curl -sSI https://vadimpianov.pages.dev/ru/   # 200
   curl -sSI https://vadimpianov.pages.dev/en/   # 200
   curl -sS -o /dev/null -D - https://vadimpianov.pages.dev/   # 302, Location: /en/ (или /ru/ из РФ)
   ```
   Для `/` — именно GET, не `curl -I`: функция обрабатывает только GET, на HEAD отдаётся статический `index.html` (200).
6. **Обновить «Состояние проекта»** ниже: дата деплоя, адрес. Закоммитить и запушить.

### Если не выходит

- **`fetch failed` / 403 от прокси на `api.cloudflare.com`**: это сетевая политика облачного окружения. Сказать пользователю: меню окружения в заголовке сессии → Edit → Network access → добавить в разрешённые домены `api.cloudflare.com` и `vadimpianov.pages.dev` (или выбрать уровень доступа шире). Не обходить.
- **`Invalid account ID "<…>"`**: см. шаг 1.
- **`Invalid format for Authorization header` [6111]**: в `CLOUDFLARE_API_TOKEN` лежит не API-токен (например, значение с `|` или Global API Key). Нужен API Token: dash.cloudflare.com → My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers» (или Custom: Account → Cloudflare Pages → Edit). Попросить пользователя заменить значение в настройках окружения.
- В CLAUDE.md не писать «задеплоено», пока шаг 5 не прошёл.

## Состояние проекта

Скаффолд готов (2026-09-25): Astro 7 + TS (strict) + MDX + i18n `/ru/`, `/en/` + GSAP/ScrollTrigger + Lenis + View Transitions.

- `pnpm dev` / `pnpm build` (включает `astro check` и проверку типов `functions/`) / `pnpm format`
- `functions/index.ts` — редирект с `/`: cookie `lang` → страна (`RU` → `/ru/`) → `/en/`
- `src/i18n/` — строки интерфейса (`ui.ts`), хелперы ссылок, выборка кейсов по локали
- `src/content/{ru,en}/cases/*.mdx` — кейсы; `hello-world.mdx` тестовый, удалить при появлении настоящих
- `src/scripts/motion.ts` — Lenis + GSAP; анимации страницы регистрируются через `onPage()`, чистятся сами при переходах
- `src/components/Hero.astro` + `src/scripts/hero-gradient.ts` — hero на весь экран с WebGL-градиентом, на курсор **не** реагирует. Палитра — `--hero-colors` в `Hero.astro`: кольцо со стопами «#hex N%» (последний цвет = первому), оттенки сдвигаются по кругу только вперёд; жёлтый ≈ 20% (два жёлтых: печёный `#e0a33a` + медовый `#f0bd4f`), розовый ≈ 30%, голубой ≈ 10%. **Каждый цвет — один сплошной участок кольца, не дробим на части**; на экране ~0.9 круга, чтобы цвет не повторялся; между голубым и жёлтым — кремовый мостик. Поверх градиента — чёрный слой 7% (`.hero__shade`). **Анимация всегда стартует с согласованного кадра** — `startTime: 9.3` в пресете `soft` (жёлтый слева, розовый в центре, фиолетовый с голубым у правого края); при изменении формулы потока стартовый кадр надо подобрать заново. Форма — «густой поток»: ленты текут и изгибаются хаотично (направление медленно поворачивается, слои изгибов дрейфуют в разные стороны), деформация ограничена, замкнутые формы («дырки», мишени) запрещены — не возвращать шум-пятна. Пресеты `HERO_PRESETS`: `soft` (текущий: медленная смена оттенков, `edge: 0.56` — переходы почти вдвое уже исходных (чётче), `timeScale: 0.525` — движение примерно в 2 раза медленнее исходного) и `vivid` (быстрее, границы резче). Пресет по умолчанию — в `Hero.astro`. Палитра общая для обоих пресетов
- `src/styles/tokens.css` — сетка, шрифт, цвета, шкала текста. Шрифт — **Onest Variable** (`@fontsource-variable/onest`, self-hosted): заголовки 800, текст 400
- Hero: заголовок «Архитектура, дизайн, процессы, ИИ» + подпись (`home.intro.*` в `ui.ts`), прижат к левой линии `--gutter`, по центру экрана по вертикали
- `site` в `astro.config.mjs` — заглушка, заменить на реальный домен

Задеплоено (2026-09-25, последний — текст в hero, шрифт Onest): https://vadimpianov.pages.dev — `/ru/`, `/en/` отдают 200, `/` редиректит (302) по cookie/стране.
